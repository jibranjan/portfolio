04 How I work

Four habits I keep

  • 01

    Measure first

    I find out which part of a slow page is actually slow before I change anything. Shaving bytes off a page that was never blocked fixes nothing.

  • 02

    Tokens, not hex codes

    Colour, spacing and type come from the system. When the system is missing something, the system changes, not one page.

  • 03

    Checked in the browser

    A diff that looks right is only a guess. I open the real page, at phone width too, before I call anything done.

  • 04

    AI agents, with checkpoints

    I work with AI coding agents every day. The work still moves through a spec, a plan, a browser check and a review, one step at a time.
